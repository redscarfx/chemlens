# 🧪 ChemLens

### Exploring molecular properties through machine learning.

ChemLens is a personal R&D project exploring how machine learning and modern AI models can be used to predict, analyze, and compare molecular properties.

The goal is to build an interactive web platform where users can search for chemical compounds, explore their molecular structures, run predictions using different models, and compare the results against known reference values.

## 🎯 Project Goals

ChemLens aims to provide a unified environment for molecular exploration and property prediction.

- **Molecular Search** — Find molecules using their chemical name, SMILES notation, or uploaded structure files.
- **Molecular Visualization** — Display and explore molecular structures.
- **Property Prediction** — Run different machine learning models to estimate molecular properties.
- **Model Comparison** — Compare predictions from classical ML algorithms, state-of-the-art approaches, and Transformer-based molecular representations.
- **Reference Data** — Build a database of known molecular properties, distinguishing experimental measurements from theoretical values and preserving their original sources.
- **Prediction Analysis** — Visualize differences between model predictions and available reference values.

## 🔬 Research & Experimentation

The project will explore different approaches to molecular machine learning, including:

- Classical machine learning and ensemble methods.
- Deep learning architectures.
- Molecular fingerprints and descriptors.
- Transformer-based molecular representations and embeddings.
- Pre-trained models and emerging approaches in AI for chemistry.

Models will be evaluated and compared using publicly available molecular datasets and established benchmarks.

## 🛠️ Technology Stack

*Initial technology choices — subject to evolution.*

- **Language:** Python
- **Cheminformatics:** RDKit
- **Machine Learning:** Scikit-learn, XGBoost, CatBoost, LightGBM
- **Deep Learning:** PyTorch
- **Molecular Data:** PubChem, ChEMBL, MoleculeNet, Therapeutics Data Commons
- **Backend:** FastAPI
- **Development:** Conda, Jupyter, Git, Docker

## 🚧 Project Status

ChemLens is currently in its early research and proof-of-concept stage.

The initial focus is on exploring molecular datasets, understanding cheminformatics tools, experimenting with different modeling approaches, and establishing a reliable evaluation framework.

More details and implementation updates will be added as the project evolves.
